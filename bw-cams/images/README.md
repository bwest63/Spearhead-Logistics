# BW Cams: Image Checklist

Drop real photos into these folders using the exact file names below. The site picks them up automatically, and anything missing keeps showing the drawing.

- Use **.jpg** or **.png**.
- Square or 4:3 images on a white background look best. About 800 px wide is plenty.
- Only use photos you have permission to use: your own photos, or images from a manufacturer or distributor dealer program.
- Prefer to link to an image online instead? Paste its web address into `PRODUCT_IMAGES` or `BRAND_LOGOS` near the top of the script in `index.html`.
- When adding new products to `index.html`, add them at the **end** of the product list so existing SKUs (and file names) do not change.
